
# 玄甲安全中心 (SecureShield)

> Windows 用户态安全防护工具 / A user-mode security suite for Windows

C++ 原生开发，无 .NET / Java 等第三方运行时依赖，体积小、常驻资源占用低。

## 功能特性

- **实时文件守护**：程序目录与信任目录变更监控，内置 YARA 规则引擎（4700+ 条规则，覆盖恶意软件 / 黑客工具 / 可疑文件名与 IOC）
- **病毒扫描**：全盘或自定义扫描、资源管理器右键扫描、压缩包内扫描（ZIP / GZ / TAR 等格式）
- **勒索防护**：诱饵文件 + 批量篡改行为检测，命中即拦截并告警
- **进程防护**：进程创建监控，仅对硬信号命中的危险进程执行免询问处置
- **自我修复**：核心文件被删除或篡改时自动从金副本还原
- **隔离区 / 信任区**：隔离文件可查看与恢复，信任路径可视化编辑
- **系统修复工具集**：断网修复、启动项检测与修复、注册表劫持检测、解除文件占用、文件粉碎
- **火绒风格进程群**：主程序之外常驻防护进程、病毒库连接进程、自保护进程；界面语言为英文时进程名自动切换
- **中英双语**：主界面与安装器均支持中文 / English

## v0.1.9.57 变更

- **移除驱动级自我防护（内核驱动）**：正常模式 Windows 下开箱即用，无需开启测试模式，不改动任何系统启动配置
- **新增火绒风格进程群**：3 个伴随进程（防护 / 病毒库连接 / 自保护），随界面语言切换中英文进程名
- **安装器双语化**：安装首屏新增语言选择，全界面跟随切换
- YARA 规则库更新（4722 条）

## 安装

1. 下载发布页的 `SecureShield_v0.1.9.57_撤驱动级防护·火绒风格进程群_源码与安装程序.zip`
2. 解压后先运行 `信任并运行.bat`（导入自签名根证书，消除"发布者未知"警告）
3. 运行 `玄甲安全中心_v0.1.9.57_安装程序.exe`，按向导完成安装（需管理员权限）

> 首次运行如遇 Windows SmartScreen 提示，选择"更多信息 → 仍要运行"。安装包已做 Authenticode 签名，发布页提供 SHA1 供校验。

## 系统要求

- Windows 10 / 11（x64）
- 约 30 MB 磁盘空间（含 YARA 规则库与样本库）
