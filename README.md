# 玄甲安全中心 (SecureShield)

> Windows 用户态安全防护工具 / A user-mode security suite for Windows

C++ 原生开发，无 .NET / Java 等第三方运行时依赖，体积小、常驻资源占用低。

## 功能特性

- **实时文件守护**：程序目录与信任目录变更监控，内置 YARA 规则引擎（4700+ 条规则，覆盖恶意软件 / 黑客工具 / 可疑文件名与 IOC）
- **病毒扫描**：全盘或自定义扫描、资源管理器右键扫描、压缩包内扫描（ZIP / GZ / TAR 等格式）
- **勒索防护**：诱饵文件 + 批量篡改行为检测，命中即拦截并告警
- **进程防护**：进程创建监控，仅对硬信号命中的危险进程执行免询问处置
- **应用防火墙**：以 Windows 自带防火墙引擎为执行者，按程序粒度管理放行 / 拦截，实时展示每个程序的网络访问记录
- **自我修复**：核心文件被删除或篡改时自动从金副本还原
- **隔离区 / 信任区**：隔离文件可查看与恢复，信任路径可视化编辑
- **系统修复工具集**：断网修复、启动项检测与修复、注册表劫持检测、解除文件占用、文件粉碎
- **GitHub 自动更新**：自动检查本仓库发布页，发现新版本即静默下载、校验并安装；可选不更新 / 自动更新 / 询问更新
- **火绒风格进程群**：主程序之外常驻防护进程、病毒库连接进程、自保护进程；界面语言为英文时进程名自动切换
- **中英双语**：主界面与安装器均支持中文 / English

## v0.1.9.59 变更

- **新增 Avast 式应用防火墙**：设置页新增 3 张防火墙卡片
  - **应用规则**：按程序逐条放行 / 拦截，列出每条规则的网络类型、协议、端口与生效状态
  - **连接监控**：实时显示正在联网的程序、目标地址与端口，可一键拉黑

- 「允许」方向的操作不需要提权；「拦截」方向会调用一个独立的一次性提权助手
- YARA 规则库维持 4722 条

## 安装

1. 下载发布页的 `SecureShield_Setup_v0.1.9.59.exe`（或 `SecureShield_v0.1.9.59_src.zip` 内的安装程序）
2. 首次运行本系列软件：先运行 `信任并运行.bat`（导入自签名根证书，消除"发布者未知"警告）
3. 运行安装程序，按向导完成安装（需管理员权限）

> 首次运行如遇 Windows SmartScreen 提示，选择"更多信息 → 仍要运行"。安装包已做 Authenticode 签名，发布页提供 SHA256 供校验。

## 自动更新

- 更新数据源为本仓库的 GitHub Releases 正式版，不经过任何第三方服务器
- 只有比当前版本新的正式版才会被安装；预发布版本不会推送
- 设置页 → 自动更新卡片，可随时改为「不更新」或「询问更新」

## 系统要求

- Windows 10 / 11（x64）
- 约 30 MB 磁盘空间（含 YARA 规则库与样本库）
