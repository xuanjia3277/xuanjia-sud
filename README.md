# 玄甲安全中心 (SecureShield)

> Windows 用户态安全防护工具 / A user-mode security suite for Windows

C++ 原生开发，无 .NET / Java 等第三方运行时依赖，体积小、常驻资源占用低。

## 功能特性

- **实时文件守护**：程序目录与信任目录变更监控，内置 YARA 规则引擎（4700+ 条规则，覆盖恶意软件 / 黑客工具 / 可疑文件名与 IOC）
- **病毒扫描**：全盘或自定义扫描、资源管理器右键扫描、压缩包内扫描（ZIP / GZ / TAR 等格式）
- **勒索防护**：诱饵文件 + 批量篡改行为检测，命中即拦截并告警
- **进程防护**：进程创建监控，仅对硬信号命中的危险进程执行免询问处置
- **应用防火墙**：以 Windows 自带防火墙引擎为执行者，按程序粒度管理放行 / 拦截，实时展示每个程序的网络访问记录
- **自我修复**：核心文件被删除或篡改时自动从金副本还原
- **隔离区 / 信任区**：隔离文件可查看与恢复，信任路径可视化编辑
- **系统修复工具集**：断网修复、启动项检测与修复、注册表劫持检测、解除文件占用、文件粉碎
- **自动更新（GitHub + 国内备用源）**：默认从本仓库发布页取新版；可额外配置备用下载源，主源不可达时自动改走备用源
- **火绒风格进程群**：主程序之外常驻防护进程、病毒库连接进程、自保护进程；界面语言为英文时进程名自动切换
- **中英双语**：主界面与安装器均支持中文 / English

## v0.1.9.60 变更

- **新增国内备用下载源**（GitHub 渠道不可用时的兜底）
  - 安装目录下多一个 `data\update_mirrors.txt` 清单文件，一行一条备用源：版本号 + 下载地址 + SHA256
  - 支持**直链**与**蓝奏云分享链接**两种形式；蓝奏云的 JavaScript 反爬挑战由客户端本地解算，不依赖任何外部脚本
  - 支持**远程清单通道**：填一个清单 URL，客户端会再取一份最新条目列表，不必逐个改
  - 主源（GitHub）与备用源合并成一个候选池，按版本号从新到旧逐个尝试，**任一源失败就换下一个**，坏镜像不会拖死可用主源
- **备用源的双重安全门**：从任何非 GitHub 渠道下载的安装器，必须同时通过
  ① SHA256 校验 ② Authenticode 签名链验证（信任锚只认本产品自带的 `cert\XuanJiaRoot.cer`）
  —— 缺根证书一律拒绝。所以填错链接最坏结果是"装不上"，不会被塞进假安装包
- **出厂清单是空模板**（只有注释行），即默认仍只走 GitHub；想启用备用源，编辑该文件取消注释即可，无需重装
- **自检新增 4 条签名门断言**：未签名的可执行文件必须被拒绝、缺根证书时必须一律拒绝、根证书必须可解析、我方签名的安装包必须被接受
- **恶意样本检测覆盖大幅扩充**：新增 37 条 theZoo 家族专杀规则（银狐 / 戴夫桌面样本集实测 142/142 目标全覆盖），YARA 规则库由 4722 条扩充至 4750 条，样本哈希 IOC 增至 27,367 条

## 安装

1. 下载发布页的 `SecureShield_Setup_v0.1.9.60.exe`（或 `SecureShield_v0.1.9.60_src.zip` 内的安装程序）
2. 首次运行本系列软件：先运行 `信任并运行.bat`（导入自签名根证书，消除"发布者未知"警告）
3. 运行安装程序，按向导完成安装（需管理员权限）

> 首次运行如遇 Windows SmartScreen 提示，选择"更多信息 → 仍要运行"。安装包已做 Authenticode 签名，发布页提供 SHA256 供校验。

## 自动更新

- 主数据源为本仓库的 GitHub Releases 正式版，不经过任何第三方服务器
- 只有比当前版本新的正式版才会被安装；预发布版本不会推送
- **备用源**：编辑安装目录下 `data\update_mirrors.txt`，填 `版本|下载地址|SHA256` 即可；该文件不在自保护基线内，可随时手工修改
- 设置页 → 自动更新卡片，可随时改为「不更新」或「询问更新」

## 系统要求

- Windows 10 / 11（x64）
- 约 30 MB 磁盘空间（含 YARA 规则库与样本库）
